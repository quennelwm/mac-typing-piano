# Mac 打字钢琴

在其他应用打字时，键盘触发钢琴音色，屏幕底部显示与按键对应的钢琴。日常控制集中在菜单栏 **♪**，不需要一直打开主窗口。

**当前协作测试版：0.2.11。** [下载可运行的Mac试用包](https://github.com/quennelwm/mac-typing-piano/releases/tag/v0.2.11-trial) · [安装和测试说明](docs/testing/Download-and-Test.md) · [反馈问题](https://github.com/quennelwm/mac-typing-piano/issues)

现成包面向Apple Silicon Mac。编译目标macOS14+，实机已验证macOS27.2；其他系统仍待测试。下载发布页中的 `Mac-Typing-Piano-0.2.11-arm64.zip`，无需编译。首次启动需要由测试者允许App运行和输入监控，具体步骤见测试说明。这个版本尚未经过Apple公证。

## 功能

- MacBook下方五排的64键，顶部整排包括Esc不参与，Fn保留。
- 64音Steinway候选采样、多音与自然尾音；每次击键有24pt、上升100pt、950ms内结束的缓升轻漂♪动画。
- ♪控制面板中，“键盘钢琴”勾选控制运行/暂停，右侧“演奏音符”开关单独控制上飘音符。
- 桌面高度滑块显示0%—100%，映射56—201.6pt主体高度并自动保存；钢琴自动适应屏幕宽度。
- ♪菜单的“琴键透明度”滑块可在0%—100%实时调节并自动保存，默认15%；0%不透明，100%材质完全透明。
- 不透明黑键为纯黑带细边光泽，黑键灰字较此前调浅；白键浅灰文字保持。标签/浮音独立于材质透明度。
- 点击模拟琴键后按实体键，在草稿中交换绑定，保存后生效；系统设置内可选琴键始终置顶或始终在底层。
- App音量与系统提醒声音量分别控制，提醒音量正常退出恢复本会话原值，外部修改不覆盖。
- 新演奏键位为唯一默认（G为中央C）；♪菜单可自定义64键音高，冲突时交换两键，保存后标签与声音一起生效，可恢复新表默认。
- ♪菜单内的音量滑块只控制本App。声音、标签和钢琴显示独立控制；“下载新版…”打开GitHub发布页。
- 使用系统原生Dock自动隐藏；Dock出现时钢琴渐隐，Dock收回后渐现。
- 可选“静音系统提示音”，缓解无输入框时系统警告声叠加，媒体与琴声音量不变。
- 不保存输入文字或按键历史；安全输入期间暂停，不增加触控板专属功能。

## 当前验证范围

0.2.11按用户布局重做控制面板、直接绑键与琴键层级，优化重复刷新和渲染缓存。主独立158项：155通过、3条件跳过、0失败；[验收记录](docs/evidence/PM-034/REVIEW.md)区分自动化、用户反馈与未测。用户已确认动画更顺和黑键字色；菜单开关存在三次循环、外部点击不收起及滑块问题仍待修复，用户要求先公开本试用版；本机0.2.10→0.2.11输入监控许可保留。离屏渲染收益不等于受控常驻CPU/内存改善，Dock查询仍有后续优化空间。固定开发签名，尚未Apple公证。

Fn/Caps/左右修饰键完整实按、多屏/侧边Dock、其他macOS版本、真实声学延迟和最终音色仍待协作测试。Dock原生适配使用隔离的私有SPI，能力不可用时引导系统设置；这是试用版，不等于正式发布或全平台兼容。
