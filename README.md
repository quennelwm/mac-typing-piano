# Mac 打字钢琴

在其他应用打字时，键盘触发钢琴音色，屏幕底部显示与按键对应的钢琴。日常控制集中在菜单栏 **♪**，不需要一直打开主窗口。

**当前协作测试版：0.2.9。** [下载可运行的Mac试用包](https://github.com/quennelwm/mac-typing-piano/releases/tag/v0.2.9-trial) · [安装和测试说明](docs/testing/Download-and-Test.md) · [反馈问题](https://github.com/quennelwm/mac-typing-piano/issues)

现成包面向Apple Silicon Mac。编译目标macOS14+，实机已验证macOS27.2；其他系统仍待测试。下载发布页中的 `Mac-Typing-Piano-0.2.9-arm64.zip`，无需编译。首次启动需要由测试者允许App运行和输入监控，具体步骤见测试说明。这个版本尚未经过Apple公证。

## 功能

- MacBook下方五排的64键，顶部整排包括Esc不参与，Fn保留。
- 64音Steinway候选采样、多音与自然尾音；每次击键有24pt、上升100pt、950ms内结束的缓升轻漂♪动画。
- ♪菜单的“钢琴高度”滑块可在50%—180%实时调节并保存，100%为112pt。钢琴自动适应屏幕宽度。
- ♪菜单的“琴键透明度”滑块可在0%—100%实时调节并自动保存，默认15%；0%不透明，100%材质完全透明。
- 水晶琴键的白键使用浅灰标签、黑键使用深灰标签；标签可开关，标签和浮音不受材质透明度影响。系统减少透明度时使用实色并暂停滑块，关闭后恢复原值。
- 新演奏键位为唯一默认（G为中央C）；♪菜单可自定义64键音高，冲突时交换两键，保存后标签与声音一起生效，可恢复新表默认。
- ♪菜单内的音量滑块只控制本App。声音、标签和钢琴显示独立控制；“下载新版…”打开GitHub发布页。
- 使用系统原生Dock自动隐藏；Dock出现时钢琴渐隐，Dock收回后渐现。
- 可选“静音系统提示音”，缓解无输入框时系统警告声叠加，媒体与琴声音量不变。
- 不保存输入文字或按键历史；安全输入期间暂停，不增加触控板专属功能。

## 当前验证范围

0.2.9加入可保存的琴键透明度滑块，保留高度调节、水晶材质、漂浮音符、新默认键位与自定义功能。主对话独立回归146项，143通过、3项离线音库条件测试跳过、0失败；证据见 [0.2.9验收](docs/evidence/PM-032/REVIEW.md)。本机0.2.8→0.2.9已验证保留输入监控许可，并启动新版后台模式；真实菜单拖动及新版实按听音尚待用户反馈。公开包沿用固定Apple开发证书签名；没有Developer ID或Apple公证。

Fn/Caps/左右修饰键完整实按、多屏/侧边Dock、其他macOS版本、真实声学延迟和最终音色仍待协作测试。Dock原生适配使用隔离的私有SPI，能力不可用时引导系统设置；这是试用版，不等于正式发布或全平台兼容。
