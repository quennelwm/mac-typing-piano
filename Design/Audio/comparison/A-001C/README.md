# A-001C 等电平对比试听

[试听 A](A.wav) · [试听 B](B.wav) · [盲听索引](blind-index.json) · [听完揭示对应关系](reveal.json)

两段都是 **15.45 秒**，来自 C-001B 的真实 AVAudioUnitSampler 离线渲染；当前声库为 **mono PCM16 试验版**，不是 A-001 的原立体声小样。比较文件为 48kHz mono PCM24，仅为增益处理保留精度，不恢复原渲染或 SF2 已丢失的信息。未进行硬件播放或人工听感确认，也未选择正式音色。

请保持设备和播放音量一致，先听 A/B，再看 reveal.json。分别记下：长听柔和度、高音舒适度、快打清晰度；允许“两者均不满意”或“无法判断”。这只是隐藏标签的小型对比，不是随机化、双盲的感知实验。

|时间（秒）|相同输入|
|---|---|
|0–1.60|MIDI42，按住750ms，释放800ms，间隔50ms|
|1.60–3.20|MIDI60，同上|
|3.20–4.80|MIDI96，同上；重点听高音|
|4.80–5.70|MIDI60，短按50ms，释放800ms，间隔50ms|
|5.70–7.55|MIDI60，按住1s，释放800ms，间隔50ms|
|7.55–13.40|MIDI60，按住5s，释放800ms，间隔50ms|
|13.40–15.45|MIDI60，10Hz重击前20次及末尾50ms静音|

全部 velocity64、引擎gain0.08；原最低音分别33/34、末尾和弦音数分别10/11，因此排除，避免不同输入干扰比较。快速段是同音重触发，不代表不同按键、多音符快速输入；原渲染只保存前20次，不能据此评估完整尾音。仅在快速片段末5ms使用相同线性淡出，消除截断边缘；其余保留原样，统一50ms间隔。

采用**整段常量增益**，目标RMS −26dBFS，并以两者共同可实现、峰值≤−6.1dBFS的目标为上限。没有逐音归一化、压缩、EQ、混响或调音；同一候选各音强弱关系保留。RMS不是LUFS，匹配RMS不保证主观等响。测量包括相同静音间隔，完整数字见 processing-record.json。

**精度限制：**所选原PCM16片段RMS约−74.3dBFS，因此统一增益约+48.3dB；这也放大量化噪声。输出24bit无法补回细节。本轮只能作初步对比，正式长期舒适度/噪声评价应由代码角色另行授权生成更高精度或合理电平的同序列引擎渲染，再复评。勿把放大后的噪声直接归因于原钢琴录音。高音判断只覆盖MIDI96等少数试验音，非全64音。

可复现：在项目根目录运行 `python3 Design/Audio/comparison/A-001C/scripts/build_comparison.py`。依赖既有Python/NumPy，无新增下载或安装。该脚本只写本任务比较目录和证据目录；原WAV、bank、源码只读。构建校验每个原渲染SHA256与C-001B结果、bank与试验索引、来源Git blob与完整根音清单；输入绑定在 docs/evidence/A-001C/inputs.json。

完整音层方案见 full-layer-plan.md / full-layer-plan.json。当前未扩展覆盖、下载、安装、调整音色或修改任何运行中的设置。
