# U-001 动效与生命周期

候选 quiet-ivory-u001.0.3。所有时间以单调时钟计算，单位ms；此规范不让 UI 直接捕获真实键盘或驱动音频。输入→协调器→音画同源的工程实现归代码对话。

## 琴键

| 状态/事件 | 视觉与时长 | 状态约束 |
|---|---|---|
| Rest | 原位、静态键面 | 不常驻刷新 |
| 新down | 45ms下沉，白2pt/黑1.5pt | 新generation；与声音同时接收事件，不等待UI |
| Held | 保持按下，无重复闪烁 | 系统重复down不重新击发 |
| up | 模型立即pressed=false，100ms回弹 | 回弹不等音频尾音 |
| 短按 | 从down起最短视觉按下45ms | 只延迟视觉回弹，不延迟真实up或音频释放 |
| 重击 | 从当前呈现位置转向按下 | 取消旧回弹任务，旧generation不得改新状态 |
| 仅隐藏画面 | 可100ms淡出；立即停效果刷新 | 声音状态不变；不补播历史 |
| 恢复 | 对当前有效pressed快照即时就位 | 多个隐藏原因全部解除才恢复 |
| 减少动态效果 | 即时明暗切换、无位移 | 取消视觉保持下限；尾音逻辑不受影响 |
| 总暂停/安全阻断 | 清空所有视觉状态和任务 | 音频panic由协调器处理 |

按压/回弹曲线候选 cubic-bezier(.2,.7,.2,1)，无过冲弹跳。标签与对应键面在同一变换父层；黑键绘制在白键上方。单个键最多一个待回弹任务，按代次失效旧任务。不得累积长按刷新。

## CR-002 小音符

- 每个有效新 NoteEvent.down 的 pressID 一枚 `♪`，12pt系统medium，灰绿 #626C66，1.25pt白色细光晕；不绑定标签开关、声音开关或音频尾音。
- 位置：本键水平中心；字形墨迹底缘在键顶上方4pt。使用本键静止顶部锚点；不跟随键回弹移动，避免上升轨迹抖动。
- 普通模式 duration=700，normalized t=elapsed/700，rise=24×(1−(1−t)^3)。透明度 min(1,elapsed/60,(700−elapsed)/400)，时间范围[0,700)。700ms及之后销毁。
- 0ms透明度0；100ms完全显示并上升约8.89pt；350ms透明度0.875、上升21pt；700ms已消失。不要把关键帧0的不可见误判为未创建。
- 64键任意白/黑键均对准自身中心；多键同时产生独立实例。重击使用新pressID，不让旧实例销毁新实例。长按重复不增生；up不生成音符，也不提前截断已有音符。
- Dock让位、用户关闭钢琴、总暂停、安全阻断：立即清除音符并停止刷新，隐藏期间不创建/排队；恢复不补播。清理音符不等于清除仍有效的输入/音频状态。
- 减少动态效果：原位淡出200ms，rise=0，opacity=1−elapsed/200；200ms销毁。切换减少动态效果时清理旧位移动画，后续击发按新设置渲染。
- 48pt透明留白独立于56pt琴键主体，总画布104pt，坐标viewBox为[0,-48,W,104]。包含光晕的全音域边界检查见qa/floating-bounds.json；留白仍鼠标穿透。

## 预览实现和边界

floating-notes.js 是独立纯时间模型，preview.js 用requestAnimationFrame绘制；空实例停止RAF。鼠标点琴键仅在这个试听/审稿预览中支持，并共用setDown路径；桌面浮层仍应鼠标穿透。没有全局输入监听、音频或真实按键存储。

示例模型使用每键最近pressID和事件时间拒绝重复/旧事件；同一单调时钟量化时间可有不同新pressID。生产输入仍须由协调器保证顺序和pressID唯一，不能靠预览代码猜真实事件。当前演示不定义正式Swift API，不应直接复制为生产状态归约器。

GIF是原生CoreText帧合成的单次短片，36帧×20ms=720ms容器；普通效果在700ms消失，最后20ms保留空状态，减少动态效果在200ms结束。GIF不循环；HTML按钮可再次触发。GIF不代表屏幕录像或实际App性能。GIF中的键面在180ms切换回静止，是离散状态参照，不用于验收45/100ms琴键连续运动。

Node真实单调时钟运行同一时间模型并定期采样，报告qa/timeline.json；浏览器绘制、真实刷新率和系统“减少动态效果”联动未在目标屏幕实测。切勿把模型计时或GIF时长当输入到画面延迟。
