# U-031 水晶材质配方 · 首批供代码接入

2026-10-29，u031.1；CR-008已授权方向。精确颜色/alpha/几何见reference.json。此处是程序化水晶风格，不称为系统原生Liquid Glass或真实折射；不采集桌面、不申请新权限。

1. 整窗alpha保持1。底座只用#526174/0.10薄透明底，不能用旧不透明深灰底座遮住背景。白键乳白、黑键烟蓝灰；每键独立路径、渐变alpha与0.7pt边缘高光，颜色按rest/pressed独立处理。黑键不纯黑，留出深灰字的可见层次。
2. 白键可见区域扣除**当前已施加按压变换的黑键轮廓**，每块可见键面只合成一次。不要半透明黑键再叠完整白键，避免叠加成近不透明/变白；可用统一可见面遮罩或even-odd裁剪，不需纹理截图。半透明材质下投影应克制，且不要整块黑色阴影填在黑键底下消耗透明度。
3. 白字固定浅灰#969FA9/0.86；黑字固定深灰#414B55/0.84。不得为了旧4.5:1标准把黑字改回浅灰。字号10/9.5pt、侧标6.5pt，独立文字层随键，绝不烘焙。新方向有意低存在感，背景样张记录实际对比度，不冒称无障碍高对比通过。
4. 主体56/112/201.6pt分别对应50/100/180%；白键高50/100/180pt、黑键32/64/115.2pt、键顶2/4/7.2pt、按压位移同比。底部位置固定；字体、边缘线宽和圆角保持pt。上方144pt留白单独计算，总高200/256/345.6pt。
5. 24pt♪从本键静止顶部上4pt开始，950ms内减速上升100pt、右漂8pt；alpha=min(1,tMs/80,(950-tMs)/500)，tMs≥950销毁。减少动态原地200ms淡出，横漂和上升都0；隐藏/切表清空不补播。
6. 系统减少透明度：改用JSON指定opaqueFallback渐变，alpha=1；仍保持白浅灰、黑深灰文字。透明区仍透明、保持鼠标穿透；不修改系统偏好。普通几何和图标无须随辅助功能开关重排。

滑块在♪菜单显示“钢琴高度”和百分比，50—180%，默认100%；拖动只重算几何并预览，松开或250ms节流保存，退出补存。缺字段/非数值100%，有限越界钳制；保存合并其他偏好，失败保留原文件/当前内存值并提示，不能丢音量/标签等设置。调高不启停音频/监听，不改映射、运行/暂停、显示意图；按住状态/释放事件连续保留。

Apple材料参考：https://developer.apple.com/design/human-interface-guidelines/materials 。有限预览与量化检查随后在本目录追加；本首批参数可先集成，不等待素材包。
