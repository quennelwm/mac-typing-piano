# U-001B 用户试用反馈增补：紧凑入口、全宽钢琴、Dock 实际显隐

2026-10-28 · UI 参数建议 `u001b.feedback.1` · 由主对话转交的用户反馈驱动。代码线程负责实装；本文件不是已实现或实测通过声明。

**实现初值：状态栏槽宽20pt，图像18pt；钢琴宽度=目标屏幕逻辑宽度−16pt；Dock实际出现淡出260ms，实际隐藏稳定120ms后淡入360ms。** 参数可直接用于候选，不要求等待新素材包。

## 1. 菜单栏单音符

截图可见一个♪，没有重复图标；截图本身不能测出状态项逻辑宽度。保留单个18×18pt模板图像、现有清晰字形，状态项固定20pt宽，居中，左右各1pt容纳图像画布；不加标题、空格、箭头或第二个音符。先采用20pt而非18pt，避免为压槽缩小字形。18pt槽仅作为后续实机确认不裁切的备选，不进入日常设置。

槽宽指应用请求的状态项逻辑宽度，不承诺相邻系统图标的中心距离等于20pt，也不修改系统菜单栏全局间距。检查1x/2x、明暗模式和菜单选中高亮；可访问名称仍为“打字钢琴”。不重新生成图标。

## 3. 以实际Dock显隐决定淡入淡出

系统Dock自动隐藏继续默认开启；原关闭确认文案和系统读回语义不变。**此处不授权UI修改系统配置，也不为增强识别增加权限。**

代码提供带显示器和位置信息的“实际可见 / 实际隐藏 / 未知”观察结果，来源与可靠性须由代码线举证。本规范不指定新的Swift接口或推测某个系统API已经可靠。

- `实际可见`：目标显示器底部中央的Dock主体已实际进入可视区域（包括展开中的部分可见），开始淡出。鼠标靠近/进入底边、Dock进程存在、自动隐藏设置开启，都不是这个证据。
- `实际隐藏`：该Dock主体已完整退出屏幕可见区域；稳定120ms后才开始恢复。鼠标离开、键盘呼出结束、菜单关闭都不能单独替代隐藏证据。
- 鼠标在底边但Dock未出现：保持钢琴。鼠标离开但Dock仍显示/菜单保持：保持隐藏。Dock在其他显示器或左右边缘：不产生本项“底部中央Dock”隐藏原因；其他场景原因仍独立生效。
- `未知`：不改最后确认的Dock状态，取消尚未完成的120ms恢复确认；已开始的淡入/淡出沿原目标完成，不因未知另起过渡。首次启动尚无确认状态时保持钢琴可见并报告识别未验证。禁止静默回退成鼠标靠边隐藏；若可靠识别做不到，代码线回报具体限制给主对话处理，不能声称已实现此反馈。

### 淡变与快速反转

- 全透明窗口内容一起变化，标签/键面共用父透明度；不滑动、不缩放。普通模式：完整淡出260ms、淡入360ms；进度`u∈[0,1]`，`ease(u)=3u²−2u³`，`alpha=a0+(target−a0)*ease(u)`。
- 新的实际可见信号立即取消恢复等待，从**当前呈现alpha**淡至0；实际隐藏稳定120ms且其他隐藏原因均解除后，从当前alpha淡至1。重复同状态观察不重启动画/恢复计时。
- 每次重定向取消旧completion/定时任务并递增generation，只有最新generation可落最终状态。持续时长按剩余距离计算：淡出`260*a0`ms；淡入`360*(1−a0)`ms，零距离立即结束。透明度连续，不跳回0或1，不叠加两套动画；不承诺反转时速度连续。
- 减少动态效果：仅透明度变化，全幅淡出/淡入均80ms，线性曲线，仍按剩余距离折算；120ms隐藏确认保持。切换设置时从当前alpha重定向；不新增位移。锁屏、权限/安全阻断、总暂停等高优先级原因立即隐藏清理，不套慢淡出。
- 多隐藏原因取并集。Dock隐藏只移除自己的原因，不能覆盖用户关闭钢琴或其他系统/安全策略。

### 音符、按键和声音

Dock实际出现即停止接收新的浮动音符、清空现有音符及待办任务；退场只淡出当时键面快照，取消其独立下沉/回弹调度。隐藏期间统一输入与音频状态照常演进，不停止声音、不改变尾音，不排队音符，也不制造新的down/up。

恢复淡入开始前，从**仍连续有效的当前pressed快照**直接放置键面；不给旧按下补下沉动画或音符。淡入开始后才允许新有效down生成音符，正常按键反馈恢复。隐藏期间发生过输入失效/安全重置，则以已清空的状态恢复，不能复用旧快照。完全不可见且无过渡时停止视觉刷新；可见状态才运行所需效果刷新。

## 4. 交接与最小验收

`reference.json` 给出3屏宽共192键的派生坐标/标签期望及上述参数；沿用冻结主题和keymap，不是新的正式theme/schema。标签墨迹来自1000pt旧基准的平移推导，未伪装成新原生字体测量。

代码候选优先检查：20pt槽内单♪；三屏宽完整64键和固定字号；仅靠底边不消失；Dock真正出现/隐藏的鼠标与键盘呼出；Dock菜单/拖拽期间仍可见时不误恢复；快速往返无闪跳；隐藏期间击键有声音且回归不补音符；减少动态和高优先级隐藏；未知状态不退回鼠标猜测。实际屏幕录像/状态来源与运行验证由代码线补齐，JSON几何检查不代替它们。
