# U-001 · Quiet Ivory 界面候选

版本 quiet-ivory-u001.0.3，2026-10-28；设计候选，等待 PM-002。已经采纳 CR-001、CR-002、CR-003。本文件不修改生产工程或已冻结接口。

## 视觉与入口

浅暖白键、石墨黑键，0.7pt 白键缝、薄灰底座、局部轻阴影。键面与灰色标签分别绘制。没有默认尾音光、彩虹或额外粒子；用户要求的小音符是一次击发一个 `♪` 的独立反馈。

产品日常入口为 macOS 菜单栏图标，点击展开/收起原生菜单。Design/UI/preview.html 是审稿工具，不是要给产品新增的主界面。菜单示意见 previews/menu-and-warning@2x.png。

菜单顺序：暂停/恢复全部；声音、音量水平滑块、显示钢琴、显示按键标签；自动隐藏 Dock、钢琴宽度子菜单；帮助/关于、退出。首次权限说明和按需试听只需轻量窗口，不扩展四页设置中心。

## 几何

| 参数 | 候选值 |
|---|---|
| 总宽 W | 900 / 1000 / 1100pt；推荐 1000pt，待用户确认 |
| 琴键主体 / 效果区 | 56pt / 上方48pt；合计104pt透明渲染范围 |
| 横向内边距 | 左右各2pt |
| 白键槽距 S | (W−4)/38 |
| 白键面 | x=2+i×S+0.35，y=2，宽S−0.7，高50 |
| 黑键面 | x=2+n×S−0.59S/2，y=2，宽0.59S，高32 |
| 黑键锚点 n | 该黑键之前的白键数量；不均分26个黑键 |
| 原点 / 单位 | 左上，y向下，逻辑pt；MIDI递增从左到右 |
| 位移 | 白键2pt，黑键1.5pt；标签与键面同组变换 |

MIDI 33—96 恰好38白26黑。首端 A1/A#1/B1 的单黑键是音域截断后的正确边界；随后按2/3黑键分组。E—F、B—C 没有黑键。音名不替代实体键标签。

900/1000/1100pt 的白键槽距约23.579/26.211/28.842pt，黑键宽约13.912/15.465/17.017pt。当前仅56pt主体高度完成渲染；48—76pt调节范围、低于900pt的布局仍未验证，不冻结支持声明。窄审稿窗口允许横向滚动，不把整条位图缩小。

## 标签规则

唯一文字来源：contracts/keymap.ansi64.v0.1.json 的 labelParts。preview-data.js 和 qa/layouts.json 均由生成器派生；集成必须仍从统一映射载入。主符号使用系统 medium，白键10pt/黑键9.5pt；主字形墨迹底缘分别距本键底4/3pt。白标签 #595959，黑标签 #CDCDCD。

L/R 为独立6.5pt角标，不与主符号拼成一张图。主符号有侧标时向左偏0.6pt，侧标墨迹右缘距本键右边1.1pt。黑键侧标墨迹底位于主符号墨迹顶部上方0.6pt；白键侧标墨迹底位于主符号顶部下方2pt，横向不相交。后者避开相邻黑键按下时的边缘/阴影，已覆盖白静/黑按等组合检查。

使用实际墨迹 bounds 对齐，不用统一文本行高硬凑。原生渲染已确认系统回退字体可用，详见 qa/layouts.json；字体文件不随资源包分发。换系统/字体版本须重测。

标签默认显示，但用户可关闭；只改变文字层可见性。关闭不改变琴键几何、映射、声音、按压状态和浮动小音符。正式 App 的 showKeyLabels 应保存并在重启恢复；此独立审稿页仅保留当前内存中的演示选择，未验证持久化。

## 组件、锚点和缩放

components 包含 white-rest / white-pressed（32×50母版），black-rest / black-pressed（19×32母版），base（1000×56），shadow（23×37，键面内容区域[2,2,19,32]）。全部 SVG，透明圆角外部，无文字、壁纸或 Dock 图标。

theme.candidate.json 逐项给出内容区域、切片边距、归一化顶部中心锚点、状态、透明通道、来源与 SHA-256。矢量的固定像素尺寸和scale不适用，明确为null；不能伪造2x尺寸。集成推荐按参数直接绘制路径，保留1/1.2pt圆角和底沿高度，不将标签随键宽拉伸；阴影用参数绘制，不作九宫格切片。

1x/2x输出分别直接在对应 backing scale 上栅格化，未将1x放大到2x。几何使用连续pt，字体在目标scale绘制；白键位置从同一个槽距计算，禁止逐键取整累积误差。原生预览以sRGB生成。previews 下整条PNG/GIF/SVG只作审稿，不能当唯一运行时资源。

## Dock 自动隐藏提醒

此项对应系统 Dock 的自动隐藏设置，候选默认开启，与钢琴自身避让独立。关闭时提示原文：

> 关闭自动隐藏后，Dock 可能与底部钢琴重叠或遮挡。仍要关闭吗？

按钮按最新 CR-001：**保持自动隐藏**（默认/取消）与**仍然关闭**。取消不改期望值或系统值；确认才交代码层提交，系统读回失败不能显示已成功。重叠提醒不是已经检测到重叠。首次运行需简要说明会影响系统 Dock；恢复原值/外部改动/失败边界按代码提案处理。

HTML只演示菜单和提醒，绝不写系统Dock；实际NSMenu/NSAlert、偏好保存、系统读回与恢复均待代码集成。

## CR-003 菜单音量与图标

菜单栏使用用户已选的单音符 `♪`。不使用高音谱号或键盘图标；图标为单色模板，正常输入不闪烁。可访问名称为“打字钢琴”。交付16/18pt、1x/2x四个透明PNG模板，原生CoreText渲染，系统回退为 .HiraKakuInterface-W5；浅深色八个样张及对应源倍率放大对照见previews/menu-icon-scales@2x.png。

集成建议由代码对话将1x/2x作为同一NSImage的表示、逻辑size为16或18pt，设置isTemplate=true，并由系统着色。若由系统字体实时生成，应匹配同一符号且重复缺字/边距检查。候选推荐18pt，16pt同时保留审稿；实际菜单栏自动着色、选中高亮与VoiceOver未测。此处是实现说明，不在本轮写生产Swift。

音量在菜单内为水平滑块，0—100%，旁边实时显示百分比，普通指针拖动不立即关闭菜单。只控制App总线的已确定增益范围，不改变系统音量或设备；0%不暂停输入/视觉；声音关闭后拖动仅改保存值，不暗中开声。生产偏好保存待代码集成，审稿HTML只存当前内存演示值。未增加触控板压力、专属手势或全局手势监听。
