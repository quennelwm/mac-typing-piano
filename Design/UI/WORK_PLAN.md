# U-001 设计与实施计划

目标：按已派发任务卡交付可审的 64 键 UI 候选，不涉及生产 App。
基线：e0c6512 原始包；开始工作 HEAD 6c25ab0。主对话管理 Git，不切分支或提交。

## 设计选择

- 推荐可组合矢量/程序绘制：几何、键面与文字独立；无新增依赖，可生成三宽度与两倍率证据。
- 全套逐键 PNG 会增加切片、缩放与维护成本；本轮不选。
- 整条图片仅作预览，无法支持逐键变换；不能作为正式组件。
- 采用轻微立体的灰阶黑白键，薄底座与小阴影。宽 1000pt、高 56pt 为候选，另交 900/1100pt。
- 灰色实体标签来自只读 keymap；黑白键各自底边对齐，侧标单独绘制，字体来自系统，不打包字体。

## 验证方法

生成器使用现有 Python 3 标准库、系统 Swift/AppKit/CoreText，不安装新依赖。
静态检查针对映射、几何、清单完整性；原生渲染检查针对真实字号/字形与图像边界。
预览浏览器中的合成演示只说明视觉行为。输入、声音、全局窗口、Dock、实机屏幕可读性与长期性能保持未测。
