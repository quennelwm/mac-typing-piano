# U-034：指定控制菜单及点琴键绑键预检

2026-10-29；UI，HEAD b74f560＋未提交C-033，按CR-012/ADR-029及用户四图。用户更正为准：首行左勾选控制整个运行/暂停，右胶囊仅控制漂浮音符。旧0.2.10两种关闭已现场失败；之前离屏布局/测试不构成关闭通过。本轮由代码C-034实现，UI只给尺寸/交互建议及最后一次冻结复核。

## 1. 可直接实现的尺寸

推荐原生瞬态popover内容区**272×340pt**，允许240—280pt但优先保留此宽；箭头/阴影由系统布局，不计内容区。浅深色使用系统材质与label/secondaryLabelColor，主字体系统13pt，灰副标签11pt；不导入字体/自绘胶囊，不照搬截图像素。单状态项♪保持16pt。

坐标以内容区左上为原点：左右边距16pt；勾选列x10、宽16；主标题及操作行x32。首行32pt高；两条滑块各30pt；分隔区12pt；声音行32pt；其后两条滑块各30pt；分隔区12pt；四操作行各28pt；上下各10pt，总340pt。必要短错误行另加22pt并自动重算高度，禁止遮盖/截断。

## 2. 状态与菜单关闭

- 首行运行勾选只有实际开始成功才on；暂停off。右漂浮开关默认on、保存，暂停时仍可改；其他设置也只保存，不恢复运行。开始缺权限沿既有明确授权流程，不把权限勾选等同于运行勾选。
- 四滑块：高度显示P=(heightScale−0.5)/1.3×100；用户拖动时heightScale=0.5+1.3×P/100。旧1.32打开后仍是1.32，仅显示约63%，不能因显示取整反写；P=0仍有56pt主体，P=100是201.6pt。透明度沿用原值/材质语义，App音量独立。提醒声音读系统alert，只有明确拖动才写，未知/失败停用该控件并给短错误/详情，不显示伪造0%；不得写系统媒体音量或开声。
- 权限行始终可见，实际授权真值打勾；点击打开输入监控页，未授权沿CR-012既有流程。打开菜单只有读取，不能请求权限/写系统音量/启动会话。
- 系统设置子项：系统声音设置、系统Dock设置、按键标签、自动隐藏Dock、琴键层级（二级：始终置顶/始终在底层，互斥）、打开测试窗口、版本更新。Dock关闭提醒保留。层级切换仅视觉，不清音/按键；底层高于桌面低于普通窗口，两个层级都让系统菜单/Dock优先。
- 推荐瞬态NSPopover支持原生NSSwitch；不另造常驻面板或全局输入钩子。♪点击toggle、外部点击/切换应用关闭、Esc关闭；滑轨拖动继续跟踪；关闭只flush偏好而不暂停。打开编辑器/系统页前先正常关闭popover；返回时不能留下不可交互的旧弹层。系统子项可用原生子菜单或popover内二级页，选择后返回或关闭行为一致。
- 真实交互验收单列：重复点♪、外部点、Esc、拖动后释放、子项→编辑器/系统页、关闭保存失败与退出补存。任何离屏/模拟调用均不能把旧关闭FAIL升级为PASS。

## 3. 点击模拟琴键后按实体键

编辑窗口建议**760×390pt内容区**，最小宽680pt；上下文标题/一句引导高44pt；模拟钢琴横向滚动区域高144pt；状态/交换摘要约64pt；底部按钮区48pt，余量给内边距。键盘内容建议1000pt宽以上，保持64键连续音位/同源标签，允许横滚；不用把全部64键压进272pt菜单或依赖空表格。复用命中几何：当前黑键形状优先，白键扣黑轮廓。

1. 打开：提示“先点一个琴键，再按电脑按键；保存后生效”。保持当前草稿/默认状态可见。
2. 点音位：用2pt系统强调色轮廓标记目标，状态“等待按键：C4 / MIDI60”；仅编辑窗口聚焦且此等待状态时启用本地捕获。
3. 实按后：显示“草稿：A → C4；G → F3（交换）”等两个方向的真实摘要，同时更新两个键的草稿标签；显示“未保存”。同一绑定给“未改变”，不生成多次交换；修饰键一次物理操作只提交一次，忽略自动重复。
4. 退出等待但保留草稿，再点其他音位可继续累计。保存成功才更新运行音画与标签；失败保留草稿并显示可重试错误。取消、关窗均不应用，恢复默认只改草稿直到保存。
5. 等待时Esc只取消等待，不绑定Esc；不在等待时保留取消/保存快捷键。保存/取消的Command快捷操作不得被捕为新绑定；Command本身仍可绑定：可暂存其down、单按松开后确认；若形成保存/取消快捷组合，则优先执行原快捷操作，不先把Command提交到草稿。失焦立即结束等待；返回需重新点音位，禁止把其他App按键写进草稿。
6. 顶部排明确排除；Fn保留且提示“本机是否可识别需实测”，不替换成Esc。左右修饰键/空格/方向键以物理ID和短标签区分，不用字符或输入法结果。绑定事件不进入后台弹奏，也不持久化原始按键记录。

建议可访问名称：“目标C4，MIDI60，当前G”“等待绑定，按Esc取消”“A绑定C4，与G交换”；选中不能仅用颜色，摘要用文字。底部按钮：左“恢复默认”，右“取消”“保存”，保存仅在草稿变化且有效时可用。
