# 打字钢琴试用 0.2.4

启动入口：[打开打字钢琴.command](./打开打字钢琴.command)。它打开固定的“打字钢琴试用.app”；请不要再打开旧的 TypingPianoProbe 或 Reviewed-C001C。

## 开始后台打字发声

1. 打开启动入口，确认显示 **0.2.4**。
2. 点击 **授权输入监控**，进入 **系统设置 → 隐私与安全 → 输入监控**，打开 **打字钢琴试用**。
3. 升级后若开关已开启但仍提示未授权，可先关闭再开启并按提示重开。**若仍失败，需移除旧条目后，用“＋”重新添加固定位置的新版App**；本机0.2.1→0.2.4实际需要此步骤，单纯切换开关没有刷新旧签名。路径为 `/Users/wuming/Library/Caches/local.typingpiano.trial/打字钢琴试用.app`。
4. 返回同一个App，点击 **重新检查并开始**（或 **开始打字钢琴**）。之后在普通应用中打字即可发声；通过菜单栏 **♪** 暂停或退出。

系统权限需要你亲自确认。App不保存输入文字或按键历史，安全输入期间暂停。

## 无需权限的试听

点击 **本窗口试弹（无需权限）**，在测试窗口里打字或点击琴键。声音同时开启；离开窗口即暂停。这个模式只用于试听，后台打字仍需上面的输入监控授权。

## 菜单和钢琴

- **♪** 菜单内的滑块只控制本App音量；标签可开关。
- 钢琴自动适应当前屏幕宽度，左右各留8点，不需手选尺寸。
- 使用macOS原生Dock自动隐藏。鼠标让系统Dock真正出现时，钢琴缓缓淡出；Dock隐藏后，钢琴缓缓淡入。声音继续，鼠标靠近底边本身不会隐藏钢琴。
- 关闭Dock自动隐藏前会提醒重叠冲突；可以取消。

声音跟随macOS当前输出设备。本机测试时使用蓝牙 **QuennelAPP**，保留了你设置的App音量，未修改系统音量。
