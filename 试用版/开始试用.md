# 打字钢琴第一版联调试用

本版可先试键盘反馈、64键画面、标签、音量菜单和700ms上升音符。完整钢琴音源与持续运行升级正在制作。

1. 在Finder中双击同目录“打开打字钢琴.command”，或打开 `/Users/wuming/Library/Caches/local.typingpiano.probe/Reviewed-C001C/TypingPianoProbe.app`。启动后只出现菜单栏♪，默认停止、静音。
2. 点击♪ → 测试 → 本窗口测试60秒，先在测试窗口按键查看响应。要在其他软件打字时响应，使用“全局观察60秒…”；若提示缺少输入监控权限，到系统设置的隐私与安全性→输入监控，为本版App授权，再退出重开。请按实际系统提示操作；命令行自检的权限结果不代表双击App身份。
3. 在♪菜单开启“声音”和“显示钢琴”；默认合成测试音覆盖64键，可先测完整按键反馈。测试菜单内可以换Kawai或Steinway B小样，但分别仅10/11音位有声。换库会停止，需要重新开启测试和声音。
4. 音量滑块只控制本软件；标签可以关闭。每次测试60秒自动停止，可重新开始；新版将提供持续会话。
5. 用“暂停全部”停止反馈，用“退出打字钢琴”结束。关闭测试控制台也会停止当前测试。

当前限制：真实Fn/Caps/左右修饰和中文输入仍待你在机器上试用确认；声音偏轻正在校准。Dock默认模拟，正常试用不会修改系统Dock；实际系统入口另有明确提示。此版本不是最终完整App，缓存目录可能被系统清理。
