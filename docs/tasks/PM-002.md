## 进入M1所需证据

1. 输入：64项能力表；普通键/左右修饰/重复/快捷键/中文的实际测试结果与环境。Fn/Caps只给真实能力，限制不能伪造通过。
2. 窗口：非激活/穿透验证，Dock各呼出路径、菜单/拖拽和支持边界。仅通过鼠标路径不能代表全部精确同步。
3. 音频：至少一种资源路线真实可加载；同音重击、自然尾音、多音/峰值有测试；引擎格式及许可记录一致。候选WAV可试听不代表SF2/DLS已加载。
4. UI：900/1000/1100pt与1×/2×预览、全64标签、侧别、黑键自身底部、几何和对比检查；至少一次主对话实际查看。
5. 用户审阅：最多两个音色小样与推荐预览可直接打开。未完成试听/审稿不得称为最终接受。
6. 跨模块：同一MIDI/映射/schema版本；资源状态诚实；外部依赖/平台/权限有明确提案。

报告可以“部分接收、M0未关闭”；不得因构建成功或文件齐全直接进入无范围的M1。涉及Fn/Dock降级、增加权限、改变硬要求由用户决定。独立工程问题由主对话裁决并写ADR，不把每个实现细节都交用户。
