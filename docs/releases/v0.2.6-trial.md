# Mac 打字钢琴 0.2.6 · 协作测试版

下载 **Mac-Typing-Piano-0.2.6-arm64.zip** 后解压，按照包内“开始测试.md”启动。完整项目源码、音源/UI资源、文档、测试与Git历史均在本仓库。

- 适用Apple Silicon Mac；编译目标macOS14+，已实测macOS27.2，其他版本待验证。
- 版本0.2.6/build9：16pt菜单栏、同进程授权返回续接、重开后主动继续、持久偏好和“下载新版…”手动更新入口。
- 菜单栏♪、App音量滑块、可选标签、自适应屏宽、系统原生Dock显隐联动。
- 新增“静音系统提示音”：用户确认后仅静音系统提醒，关闭/正常退出恢复本次原值；外部改动保护，异常退出需手动恢复。
- 89项主回归独立通过；真实菜单组件宽16点，提示音后端实测69%→0→69%，媒体输出/输入音量及总静音未改变，没有额外权限提示。组件验证不代表完整新App首次授权及声学验收。
- 此前0.2.4普通实按发声由用户确认；0.2.6首次安装需重新确认输入监控并实按核对。Fn/Caps/双侧键、多屏及延迟仍需测试。
- 使用固定Apple开发证书签名，尚无Developer ID签名和Apple公证；首次运行/输入监控需要测试者本人在系统设置确认。详细步骤见 [安装和测试说明](https://github.com/quennelwm/mac-typing-piano/blob/main/docs/testing/Download-and-Test.md)。

SHA256SUMS.txt用于核对下载ZIP。不要把GitHub自动生成的Source code.zip当成安装包。问题请提交到仓库Issues，并提供芯片、系统版本和复现步骤。
