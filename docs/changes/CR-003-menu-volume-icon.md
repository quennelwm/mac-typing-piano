## 已确定体验

- 首版不增加触控板压力、专属手势、延音区、力度控制或全局手势监听。普通指针点击/拖动菜单滑块及试听预览仍按系统正常行为工作，不额外占用手势。
- 菜单栏使用单个单色音符♪，点击展开/收起现有下拉菜单；不增加文字常驻栏或复杂主界面。菜单栏模板图像按浅/深色系统环境自适应，有“打字钢琴”可访问名称。
- 音量采用下拉菜单内的水平滑块，可连续拖动并显示0—100%的当前值。控制本App音频总线，不改变macOS系统音量或输出设备；最大值对应应用已选定的增益上限，不代表提高系统到满音量。
- 滑块值保存。0%静音但不暂停监听/视觉；“声音”开关仍独立，关闭声音后拖动只调整保存值，不暗中打开声音。菜单滑块拖动期间保持可操作，不因首个点击立即关闭菜单。
- 沿用现方案：标签开关、系统Dock自动隐藏及关闭提醒、每次击发700ms小音符。图标♪与浮动音符一致，但图标不随每次打字持续闪烁。
