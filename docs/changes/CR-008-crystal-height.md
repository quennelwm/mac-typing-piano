# CR-008：可调高度、水晶琴键与更高漂浮音符

用户2026-10-29明确要求：琴键高度可用滑块调节；音符上飘更高；稍透明水晶琴键、贴近苹果液态玻璃风格；白键浅灰标识、黑键深灰标识，只稍微可见。主PM-031负责验收，C-031唯一生产实现，U-031视觉规范。基线8142d59，候选0.2.8/build11。

## 交互与尺寸
- ♪原生菜单新增“钢琴高度”水平滑块，50%—180%，100%为现有112pt琴键主体。默认100%，已有用户配置缺字段兼容112pt；显示百分比，拖动实时预览，保存并在重开后恢复。
- 高度只缩放琴键主体的垂直几何、黑白键比例和按压位移；字体保持可辨小字，不把整张琴键与文字作位图拉伸。标签仍位于每个键自身底部，跟随按压；宽度仍目标屏幕减16pt、底边固定。
- 音符24pt，最大上升从48pt改为100pt，横漂最多8pt，950ms完整结束，采用柔和减速而非直线匀速。上方透明空间144pt，独立于琴键高度，不裁剪音符。
- 调高度不启动/停止输入或音频、不改变音量、音源、运行/暂停/显示意图和当前映射；不可使按住键丢失释放或卡音。几何更新与预览命中区域一致。透明留白鼠标穿透。
- 偏好写入节流或拖动完成保存，退出时补存最后值；非数值/越界安全处理并保留其他偏好。

## 视觉
- 采用轻透明水晶风格：逐键透明底色、柔和圆角、细边缘高光、内侧明暗和克制的投影。白键偏乳白玻璃，黑键偏烟灰玻璃；保留键形层次与黑白排列，整体不过度透明。
- 标签明确反转原对比度策略：白键浅灰、黑键深灰，以用户要求的低存在感为准；黑键本体不能纯黑到标签完全消失。文字独立绘制，禁止烘焙。
- 优先可移植程序化逐键矢量与alpha合成，维持macOS14+兼容。风格参考Liquid Glass，不声称手工高光等于系统原生折射。若选择原生材质，必须说明版本、遮罩、性能和旧系统退路，不能为视觉申请屏幕录制或截取桌面。
- 系统减少透明度时使用同色系实色退路；减少动态时沿用短淡出；不修改用户系统辅助功能设置。
- 参考：https://developer.apple.com/design/human-interface-guidelines/materials 。UI给出可组合参数/素材，不只交完整效果图。

## 验收
- 50%、100%、180% × 宽1264/1496/1904，64键/标签边界正确，按压和透明区不裁剪。
- 白/暗/彩色模拟背景证明真实alpha而非把整窗口减透明；各键文字轻淡但不全消失。减少透明度有明确退路。
- 音符0/475/949/950ms采样；950ms已清理，正常/减少动态均不裁剪；透明留白不会压缩琴键。
- 老偏好无新字段可读；新高度跨重建/重开保持；保存失败不静默丢失现有设置。拖动时运行/暂停/静音/自定义映射均保留。
- 静态显示、floating窗口层级、Dock真实避让和独立系统阻断回归；无新权限、无输入记录、无音源变化。
- 最终签名沿用固定身份和Bundle ID，与0.2.7的DR一致；临时ad-hoc候选不启动GUI，不替换已授权App，主签名后封存临时候选再安装。
