# CR-009：琴键透明度滑块
主PM-032，代码C-032，UI复核U-032；基线fe4c65d，目标0.2.9/build12。

用户：♪菜单增加琴键透明度滑块，实时调节并自动保存；黑键深灰标字、白键浅灰标字。

- 菜单位于高度旁，标题“琴键透明度”，0%—100%，0不透明/100琴键材质完全透明，整数百分比；默认15%近似0.2.8现有轻透风格。旧偏好缺字段默认0.15，非法值安全处理，有限越界钳制。
- 使用统一键面alpha=1-transparency（颜色渐变沿用U-031）。底座、边缘高光、投影按相同有效不透明度衰减；0%键面中心alpha1，100%无材质残影。保留白键扣除按压黑键形状。
- 标签独立，白#969FA9/0.86，黑#414B55/0.84，不能反转、不能随材质fade；浮音也独立。Dock整窗fade仍作用整体，不改其规则。
- 系统减少透明度时有效键面实色，保存用户设定不覆盖；菜单滑块禁用并简短说明系统设置正在生效，关闭系统减少透明度后恢复保存值。不修改系统设置。
- 复用高度的250ms节流、菜单关闭/退出补存、统一dirty失败重试/退出取消。保留当前heightScale、volume、showLabels、自定义键位和输入/播放/按住状态；不启动额外输入或音频。
- 只做必要针对性测试：旧偏好/往返/范围，原生slider动作，0/15/50/100像素与标签/音符独立，辅助功能覆盖/恢复，真实控制器保存不丢其他偏好。最终全套一次；新增问题修复才重跑。
- 旧0.2.8运行包保持至验收；候选仅CLI/离屏，不启动ad-hoc GUI。正式签名固定身份、同DR、相同安装路径，由主完成。发布仍沿用现有GitHub授权。
