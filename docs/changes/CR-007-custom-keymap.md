# CR-007：新表为唯一默认，用户自定义键位

用户2026-10-29直接确认：“直接用新表，旧表不用了，然后增加一个可以自定义按键的功能”。覆盖CR-006中保留旧预设及默认假设。主PM-027统筹，代码C-028、设计U-028；合入同一0.2.7/build10候选，C-027前三项继续。

## 已授权范围与实施选择
- 新表是唯一出厂默认。旧表保留历史契约/验收参考，不再出现在运行时选择菜单，也不依赖旧表才能启动正式包。
- ♪菜单增加“自定义键位…”与当前“默认键位/自定义键位”状态。使用简洁非复杂主界面的设置窗口，无需新权限，不监听/记录用户输入文字。
- 在窗口选一个现有实体键（左右修饰可分）和一个MIDI33—96音高，明确展示琴名/八度。仍排除顶部整排，Fn保留。标签持续表示实体键，音高和黑白位置随有效映射一致变化。
- 主对话已向用户说明的一一对应实施选择：音高已占用时交换两个实体键的音高，展示例如“A：F3→C4；G：C4→F3”。不默认覆盖对方/引入重复、缺音；64键64音不变。
- 编辑草稿不立即影响运行。取消不改当前设置；保存先完整校验并原子持久化，再应用；恢复默认先放回编辑草稿，保存才生效。未保存关闭等同取消，界面明确显示待保存状态。
- 自定义配置放当前用户Application Support，App更新保留；schema/version和64个已知实体键/MIDI双射均校验。错误配置应保留原文件、明确通知并安全回退新默认，不能拖垮App；保存失败则保留既有运行映射和可重试草稿。
- 应用时清理旧声部、按键状态、延迟释放、漂浮音符及旧输入代次，标签和音高原子替换。保持应用前运行/暂停以及声音开关、音量和显示意图；不能静默永久停掉正在运行的会话，也不因修改键位新增授权。安全输入、锁屏等阻断仍优先。

## 验收
1. 新表64项逐项对应附件，生产无旧预设入口。
2. 两键交换、连续多次编辑、取消、保存、重开加载、恢复默认均有自动化证据。
3. 损坏/重复/越界/未知实体/旧schema/写入失败配置有受控处理，不丢既有用户内容。
4. 按住期间保存后无卡音、高亮或历史音符；运行、暂停、静音三态保持，正常输入不被拦截。
5. 不改变原C-027的112pt主体、96pt效果区、24pt/900ms动画、独立静态显示与Dock规则。
6. 睡眠/会话失活/锁屏分别记录原因；任何单独恢复不能清除其他阻断（独立审查发现）。

不扩展导入导出、任意顶排绑定、多套预设库、额外音域或触控板功能。实际键盘/声音与完整系统通知顺序尚待实测，不用静态测试冒充。

主设计复核：自定义仅“已生效快照B／窗口草稿D”两份状态。选目标音高立即交换D并更新B→D累计预览，切换实体键保留D；不增加“继续调整”或额外待选候选层。最后一次保存全部，取消全部丢弃。
