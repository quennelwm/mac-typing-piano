# CR-002／击键上升小音符

日期：2026-10-28。用户要求：每次点击琴键，在该琴键上方出现一个小音符，缓缓上升后消失，完整动画在1秒以内。

## 体验与初始参数

- 每次有效击发出现一个小音符，默认开启。采用单个 `♪`，初稿12pt，位置对准所触发琴键的水平中心，在该键顶部上方4pt出现。
- 初稿总时长700ms，向上移动24pt，使用平滑ease-out；前60ms淡入，后400ms淡出。出现到销毁不得超过1000ms，不循环、不飘满屏、不旋转、不喷发多个符号。
- 700ms/12pt/24pt为主对话给UI联调的初值，用户硬要求是小巧、对应琴键、缓缓上升及1秒内结束。颜色/细阴影由UI根据背景可辨性给出方案。
- 真实键盘打字、支持的修饰键脉冲以及按需试听预览里的鼠标按下共用击发语义。按下立即触发，松开不再生成；长按的系统重复不生成，松开后重新按下生成新音符，多键各自独立。
- 桌面浮层继续鼠标穿透，不因本效果截获用户在底下App的鼠标点击；鼠标点琴键的交互仍限于试听预览。未增加复杂主界面或菜单项。

## 生命周期与独立性

- 用NoteEvent.down的pressID去重，每个有效新击发一个视觉实例；实例有自身单调开始时间。输入pulse经既有协调器生成一次击发，不在两层重复生成。
- 这是击键反馈，与音频尾音和可选residualGlow分别管理。关闭声音时仍可显示；关闭按键标签只隐藏标签，不隐藏小音符。
- 琴键松开后可回弹，小音符仍按自身700ms完成；不为等动画而延后发声或释放。重击实例独立，旧动画完成不能删除新实例。
- Dock避让、关闭钢琴显示、暂停或安全阻断时立即清理全部浮动音符，隐藏期间不生成/排队，重新显示不补播。空闲时不持续刷新。
- 系统“减少动态效果”开启时，用原位置约200ms淡出代替上移，仍保持短促反馈。

## 绘制范围

- 现有默认56pt仍指琴键主体，不把琴键压矮来容纳动画。上方增加透明效果留白，初稿48pt，覆盖起点/上移/字形高度及描边余量；实际需UI边界检查。
- 符号在琴键层上方独立绘制，不烘焙入琴键图片，不遮挡底部标签，不被56pt主体裁剪。透明留白仍鼠标穿透，整体隐藏与Dock避让一致。
- 主题在现有motion对象中新增可选floatingNote配置，themeVersion升为classic-draft.0.2；旧主题缺该字段时采用本初稿默认，未知主题版本不能静默改成无效果。schema结构允许该扩展，不更改keymap/音源格式。

## 角色任务与交付

- U-001：在原允许目录内补独立动画预览及0/100/350/700ms关键帧；覆盖白/黑键、多键、快速重击、隐藏、标签关闭、减少动态效果，交样式/字形来源、曲线和留白几何参数。预览真实计时，不能只交静态图声称动画通过。
- C-001：增加击发到瞬时实例的契约/纯逻辑准备，验证去重、旧实例清理、重击独立、隐藏清理及到期回收；正式App渲染集成按后续M1任务接入。不得重写音频引擎来驱动画面。
- A-001：范围不变，不增加额外提示音或改变音频尾音。
- PM-002：评审动画预览及计时/边界证据；正式App实测仍单列未测。

## 验收 U-09 / U-10

- U-09：每次有效新击发有且只有一个对应小音符；普通模式平滑上移并完全消失，总时长≤1000ms；快速重击与多键独立，长按不连发。
- U-10：标签关闭/声音关闭仍按规定显示；隐藏即清理且不回放；白/黑键顶部无裁剪，透明留白不挡鼠标；减少动态效果不明显位移；过期实例回收，无常驻动画负担。
