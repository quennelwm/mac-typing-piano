# CR-011：纯黑有光泽的黑键

用户在PM-033进行中追加：没有透明度时黑键应为纯黑色带点光泽，而不是灰色。本项与紧凑菜单一起交付0.2.10/build13，不替代CR-010。

- transparency=0时黑键主要键面以#000000实色绘制；光泽只在窄局部高光/边缘表现，不能用铺满灰/蓝灰的渐变作为黑键底色。主体中心为黑且alpha=1；系统减少透明度强制实色时也使用同样黑底。
- 透明度滑块继续只控制材质；中间值按透明合成自然透出背景，不修改用户当前0.12偏好，100%依然完全隐藏材质。
- 黑键深灰文字#414B55/.84、白键浅灰文字#969FA9/.86保持；白键材质、键位、尺寸、音频、动画生命周期与漂浮音符不变。按压仍有几何变化/局部反馈，避免整个黑键泛灰。
- C-033追加允许PianoView及相关渲染测试/证据；U-033追加局部视觉复核。验证26黑键主体像素、少量高光可见、透明度0/50/100和减少透明度，给一张不透明局部预览即可；继续保留明确实测/离屏边界。
