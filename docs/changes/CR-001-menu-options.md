# CR-001／菜单栏主入口、可选标签与系统 Dock 自动隐藏

日期：2026-10-28。依据：用户提出三项调整，并明确确认“是，控制系统 Dock 自动隐藏”。本变更和 ADR-010 优先于原 v1.0 及历史启动消息中相冲突的描述。

## 产品方向

1. 主入口使用 macOS 菜单栏图标，点击展开/收起原生下拉菜单，必要时使用子菜单。首版不做复杂主窗口或四页设置中心。授权说明、测试/试听预览、关于信息可用按需打开的小窗口，不作为日常必经界面。
2. 提供“显示按键标签”勾选项。用户未要求改变此前默认，因此沿用默认开启，作为可调整的工程默认。关闭只隐藏文字层，琴键、动画、映射、声音继续正常；重新开启立即显示当前映射。偏好保存。开启时仍要求64个琴键自身底部的灰色标签、左右标识和随键移动。
3. 提供“自动隐藏 Dock”勾选项，控制 macOS 系统 Dock 的自动隐藏，默认开启。该系统设置与钢琴浮层自身避让分别管理；关闭系统自动隐藏不关闭钢琴避让、不触发静音或总暂停。

## 菜单与提醒

主菜单保留：暂停/恢复、声音开关与音量、显示钢琴、显示按键标签、自动隐藏 Dock、少量外观/行为子菜单、帮助/关于、退出。

关闭 Dock 自动隐藏时，显示：“关闭自动隐藏后，Dock 可能与底部钢琴重叠或遮挡。仍要关闭吗？”

按钮：“保持自动隐藏”（默认/取消）和“仍然关闭”。仅用户选择“仍然关闭”才提交关闭动作；取消不改系统值和应用偏好。提示是本项操作的一次确认，不是每次启动反复弹窗。重叠风险不代表已经检测到实际重叠。

## 系统控制的工程边界

- 用户批准产品具备控制系统 Dock 自动隐藏的功能；本轮只更新设计/开发任务，不实际改变当前 Mac 设置。
- 默认开启指新用户默认偏好，在用户启动正式应用并启用运行时应用该设置；构建、离线测试、生成预览不能写系统偏好。首次运行简要说明影响系统 Dock。
- 区分期望偏好、系统读回值、应用成功/失败/未知；失败不得把菜单标成成功，不能悄悄申请额外权限或反复写入。
- 工程默认：首次实际更改前保存原值，正常退出只恢复本应用仍拥有的改动；检测到外部设置变化时尊重现值，不强制覆盖。生命周期方案需代码提案/测试，尚未实测；崩溃和外部修改的边界需如实报告。
- 不注入/重绘 Dock，不改位置、大小或其他偏好。读写路径、权限影响及是否需要刷新/重启 Dock 由 C-001 提案，主对话审核后安排现场验证，不能猜测成功。
- Dock 常显时继续保守避让；提示后继续不代表允许钢琴抢焦点或拦截 Dock 操作。

## 接口

- `showKeyLabels: Bool = true`：用户偏好，独立于琴键显示/声音；`UITheme.labels.visibleByDefault=true`只定义首次默认，不强制始终显示。
- `autoHideSystemDock: Bool = true`：用户期望值，独立于 DockAvoidance；实际读回/恢复状态由代码层实现并交接。
- 未改变keymap、MIDI、音频格式、主题字段类型或schemaVersion。关闭标签合法，主题不能静默覆盖用户选择。

- U-001：保留三宽度带标签预览，补每宽度至少一张无标签预览、精简菜单及Dock关闭提示示意，不扩展复杂设置主界面。
- A-001：资源范围不变，两个新开关均不改变音频事件或尾音。
- U-07验收：菜单栏主入口可展开/收起，常用功能无需复杂窗口。
- U-08验收：标签默认开启，关/开及重启偏好生效；关闭不停止音画或清空按键。
