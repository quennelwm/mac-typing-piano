# CR-012：用户指定控制菜单、直观绑键、层级与关闭修复

PM-034，0.2.11/build14；接续尚未提交的C-033，不覆盖/丢弃它。用户现已恢复实施授权；0.2.10原生菜单两种关闭实测失败，不能因150项测试通过就称菜单验收完成。原0.2.10不发布。

## 最新指定布局（覆盖CR-010）
1. 左预留勾选列：“键盘钢琴”；左侧勾选控制整个软件运行/暂停（用户最新更正，覆盖先前视觉显示解释）。右侧灰小字“演奏音符”与胶囊开关，单独控制上飘音符、默认开、保存。运行/暂停决定输入、声音和画面，暂停时其他控件只保存不恢复运行。若开始缺权限，沿既有明确授权流程。
2. 缩进灰小字“桌面高度”，0%—滑块—100%；映射既有0.5—1.8高度范围，既有1.32实际高度保留，仅展示归一化约63%。0不等于隐藏，最大仍201.6pt，不突然占满屏。下行“透明度”，0%—滑块—100%，维持现值。
3. 分隔线。“按键声音”勾选/开关表达同一声音启用状态；右侧胶囊开关（旁灰小字开/关或原生可访问状态）与左状态同步。下行“音量大小”0—100只调App，下行“提醒声音”0—100控制系统alert volume，不修改系统媒体/琴声音量；只有用户拖动才写，读回/失败/外部变更保护，沿既有正常退出恢复本会话原值机制。打开菜单绝不写系统值。
4. 分隔线。自定义键位；键盘权限授权（点击打开系统输入监控页，授权状态真值打勾）；系统设置；退出软件。系统设置收纳系统声音、系统Dock、测试窗口、版本更新；保留既有按键标签开关和自动隐藏Dock（关闭提醒不删），将新琴键层级放此处。

按用户第三张图用紧凑灰小字和原生胶囊开关，统一缩进、对齐与间距。宽度允许约240—280pt以容纳用户单行标题/副标题/开关，不勉强180而裁切；实际尺寸以UI建议和测量为准。不要恢复大段运行状态/重复说明行，错误用短提示/可访问详情。

## 菜单关闭
必须调查0.2.10重复点图标和外部点击均无效的原因，记录真实/模拟证据。允许为用户要求的胶囊控件使用瞬态NSPopover/适当原生承载视图；如改架构，说明根因/取舍，保留♪单状态项16pt、点击切换、外部点击关闭、Esc关闭、拖滑块不误关、关闭/退出补存。关闭不是暂停，弹窗/编辑窗口切换不得留下僵死菜单。不要新增吞鼠标或输入的全局权限/事件钩子。

## 点击琴键直接绑定
自定义窗口显示可点击的模拟钢琴（64音同源几何，可滚动/缩放，黑白命中正确）。先点击音位再实按电脑实体键，即记录草稿绑定并更新标签；最后保存才应用。重复绑定仍使用既有两键交换保持64键双射、解释交换结果；取消/关闭不生效，恢复默认可用。排除顶部排，Fn保留受限说明；支持左右修饰/空格/方向/常用键；只在编辑窗口聚焦且主动等待时本地捕获，不写真实逐键历史，不吞其他App输入。弹奏后台与绑定模式隔离，编辑动作不误触其他菜单/全局快捷键；Esc取消等待，保存/取消按钮的快捷操作正常。保存后音画/标签统一。

## 琴键层级
系统设置→琴键层级→“始终置顶”/“始终在底层”互斥、保存，默认保持此前置顶。置顶高于普通应用窗口，底层低于普通窗口高于桌面背景，不能抢焦点/阻断输入；系统菜单/Dock优先避让/安全暂停不变。切换不暂停声音/清空键位，睡眠/屏幕变化后保留选项，不通过频繁orderFront循环抢位置。

## 验收
真实菜单关闭由主/用户现场确认；不能只凭NSMenu绑定或mock报告通过。原生控件回调/持久化、暂停与开关解耦、alert读写恢复/失败、64键点击+按键草稿/保存取消、层级选择/偏好迁移/不改声音等有意义回归。主最终冻结源独立回归及固定身份签名/同路径安装、授权保留核对。代码不动当前用户App/TCC/偏好，不发布；主安排。黑键纯黑/标签配色继续CR-011。

## 用户追加：常驻性能
同步调查当前0.2.10 CPU/内存高占用，按PERF-034采基线。C-034据证据优化：空闲避免持续重绘/不必要菜单刷新/高频昂贵Dock枚举，音频状态与安全保护不得破坏；低频休眠/合并刷新/资源预热等以实测选择。静止、动画/输入和菜单场景分别记录，最终同环境前后对比。不可虚报没有测过的空闲/输入数值，不为降CPU砍按键声音/动画或真实Dock行为。

## 用户追加：动画卡顿与黑键标字
用户实机反馈琴键和上飘音符卡顿，纳入性能优化；需记录帧间隔/绘制耗时分布或固定合成帧基准，不能仅以Timer设60Hz称流畅。优先避免主线程阻塞、动画每帧重复全琴键昂贵绘制；保持约950ms/100pt漂浮与按压回弹语义，不用缩短动画/砍帧率掩盖问题。黑键标字从#414B55/.84调浅为建议#68717A/.90（UI可同阶微调，主接收），灰而清楚，不刺眼；白键#969FA9/.86保留。此最新文字要求覆盖CR-011旧黑字颜色。
