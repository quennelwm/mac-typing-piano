# Mac 打字钢琴｜演奏键位优化 v0.2（讨论稿）

日期：2026-10-29  
状态：**候选映射；尚未实机验证，未获用户批准替换现有映射**。

## 1. 设计出发点
- MacBook 美式 ANSI 内置键盘 **底下五排，64 个实体键**；排除 **顶部 Esc / F1-F12 / Touch ID**，不得借这些键控制八度。
- **64 个独立音高 A1-C7（MIDI 33..96），38 白＋26 黑**；键盘五排不是钢琴键盘，不能在所有五个多八度范围内复现真实钢琴手位。
- 保留后台打字背景音用途，新增**独立的演奏映射预设**；不得悄悄覆盖现有背景音预设。
- 用户强调 Shift、Command、Option、Fn、空格也可参与发声；本映射全部保留，但系统级组合键、修饰键事件和 Fn 的真实能力需实测。

## 2. 为什么核心只选 20 个音
之前提议的 F3-F5（25 音）将左手延伸到 M，却让右手从 Y 开始。**MacBook 实体键盘上存在横向重叠**，不宜作为真正双手演奏的核心手位。

新版把主手位放在同一物理排：
- **白键：A S D F G H J K L ; ' Return**，由左向右对应 F3 G3 A3 B3 C4 D4 E4 F4 G4 A4 B4 C5。
- **黑键：W E R Y U O P [**，对应 F#3 G#3 A#3 C#4 D#4 F#4 G#4 A#4。
- 左手五个白键 `A S D F G`，右手七个白键 `H J K L ; ' Return`；两个大拇指在 G/H 附近相接，**G=C4**。
- Q 行中的黑键在 A 行白键上方，符合电脑键盘“上一排是黑键”的操作感觉。左手白键尾音 C4，右手从 D4 开始，实际谱子需要右手 C4 时可以伸到 G。
- 该 20 音是 **F3..C5**，并不是“完整两组各两个八度”。换手、跨越黑键、演奏高速音群仍会受普通键盘几何限制。

## 3. 其余 44 音的处理
外围总计低音 **A1..E3：20 音**，高音 **C#5..C7：24 音**，都留有固定实体键。为了便于对照与实机测试，当前提供一份**完整且不重复的候选分配**（见 JSON）。

**注意：外围映射是可测试的覆盖草案，不是“像真钢琴一样好弹”的定稿。** 64 个物理键只有有限的横向空间，外围键不可避免地跨行、转折或落在方向键/修饰键上。这尤其意味着不能承诺完整乐谱可沿真实钢琴指法不变地弹出。

## 4. 模式与声音
- **日常打字**：默认使用原有背景音映射与音量规则，键盘全局监听只观察不拦截；原有设置和 Dock 行为不变。
- **双手演奏**：用户显式切换；使用此候选 64 键映射，优先完成专用获得焦点的演奏测试窗口；后台全局快捷键仍需遵守系统行为，不应许诺全部能劫持。
- 两种模式的实体键 ID、音高和钢琴 UI 标签均从同一映射数据读取；**不要把灰色键名烘焙到钢琴 PNG**。
- 钢琴 UI 继续固定 64 键、38 白＋26 黑，**琴键底部常驻灰色小字**；必要时仅很轻地强调 C4、C5 与主音区，不增加浮层高度。

## 5. 对比与真实验证
A. A 行白/Q 行黑的主方案：原生琴键连续性与左右手分离。  
B. Z 行左手/U 行右手的备选方案：分层更明显，但双手在不同纵向键盘排，便于比较手腕与指法疲劳。  
C. 旧版 25 音方案：保留做 A/B 对照，不作为首选，因左右手横向重叠。

实机须测：
1. 所有 64 个实体键的按下、松开与标签；Fn/Caps Lock 单列能力报告。
2. 左手和弦 **A+D+G = F3+A3+C4**；右手和弦 **K+;+Return = F4+A4+C5**；再测试双手同时六键是否丢键或触发快捷键。
3. F3..C5 音阶正反、半音、和弦、跨音，统计漏键和错音；左右手各试奏 5-10 分钟。
4. 低音 C3~E3 到 F3、C5 到 D5~G5 的频繁接续是否难以操作，作为外围映射迭代依据。
5. macOS 中文输入、日常快捷键、Dock 避让继续正常；演奏模式默认不抢其他应用输入。

## 6. 代码交接与验收边界
- **主对话**：维护本文件与决策记录，决策前不改正式默认映射。
- **代码对话**：实现数据驱动 Profile、读取映射、切换预设、渲染标签，编写 64 键唯一性测试和 20 音连贯性测试。
- **音效对话**：复查 F3-C5 主音区采样音量一致性、起音延迟、和弦削波，避免音域过尖；不改键位逻辑。
- **UI 对话**：琴键显示 64 键，动态绘制灰色键名，不调大主钢琴浮层；主音区可以增加可关闭的轻微标记。
