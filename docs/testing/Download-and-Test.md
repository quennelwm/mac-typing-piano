# 下载和测试 0.2.6

这是可运行的 Mac 打字钢琴协作测试版。无需下载完整源码或编译即可试听。

## 下载

打开 [0.2.6 试用发布页](https://github.com/quennelwm/mac-typing-piano/releases/tag/v0.2.6-trial)，下载 **Mac-Typing-Piano-0.2.6-arm64.zip**。不要把 GitHub 自动提供的 Source code.zip 当作安装包。

现成包适用于 **Apple Silicon Mac（M 系列芯片）**。程序编译目标为 macOS 14+，当前实机验证环境为 macOS 27.2；其他版本仍需要本次协作测试。没有 Windows 版或已验证的 Intel 安装包。

## 第一次启动

1. 解压ZIP，把“打字钢琴试用.app”放到固定位置，例如你的“应用程序”文件夹。不要同时保留多个正在运行的副本。
2. 双击App。公开测试包使用固定的Apple开发证书签名，但还没有Developer ID签名和Apple公证；如果系统阻止打开，请核对下载来源，按 [Apple官方打开说明](https://support.apple.com/zh-cn/102445) 处理针对这个App的“仍要打开”。不要关闭整个系统的安全保护。
3. 点击 **“授权并开始”**，在系统设置的“输入监控”允许打字钢琴，再返回App。程序会继续完成刚才明确发起的开始操作；如果系统要求退出重开，重开同一个App后再点击一次“开始打字钢琴”。重开不会仅凭旧待办记录自动启动。
4. 在普通文本框实按几个字母，确认琴声。日常使用 **♪** 菜单调整音量、标签、显示、暂停和退出；“打开启动窗口…”可找回启动入口，“测试”子菜单仅用于诊断。

没有输入监控权限时，仍可用“本窗口试弹”打字或点击琴键，声音跟随Mac当前输出设备。安全输入或音频设备错误应按对应提示处理，不需要反复授权。

如果安装过旧的ad-hoc开发包，旧条目已开启却仍提示未授权，请退出钢琴，在输入监控列表移除旧条目，再用“＋”选中当前固定位置的新App，由你亲自确认添加。本机旧ad-hoc签名失配曾导致重复授权失败；0.2.6开始使用固定开发证书，但首次从旧签名迁移仍可能需要这一步。跨版本真实授权保留还需实机验证，不能保证永远无需重新确认。

## 获取后续更新

从♪菜单选择 **“下载新版…”**，或打开本仓库 [Releases](https://github.com/quennelwm/mac-typing-piano/releases)。下载新版本的App压缩包，正常退出旧App后替换完整App，再重新打开。0.2.6起偏好保存在你的用户Application Support目录，不随App替换而删除。

上传源码本身不会生成新安装包；开发者还需要构建并发布新的Release。当前是手动下载更新，没有自动安装器，也不会静默替换程序。

## 这一版的体验

- MacBook下方五排的64键映射，顶部整排包括Esc均不参与；Fn保留。钢琴自动适应屏幕宽度。
- 每次击键出现一个上升小音符，约700ms结束。标签可关闭。
- 音量滑块仅影响本App；默认50%，不改系统媒体音量。
- “静音系统提示音”可选：用户确认后把系统提示音音量设为0，也影响其他系统警告；关闭选项或正常退出恢复本次原值，外部修改不覆盖。原本已静音时不猜测恢复值；异常退出需在系统声音设置自行恢复。
- 启动时默认启用系统原生Dock自动隐藏。Dock真正出现时钢琴淡出，收回时淡入；隐藏画面不停止声音。
- 关闭Dock自动隐藏会先提示冲突。退出时仅按本会话对Dock设置的改动情况恢复，保护用户后来做的外部修改。
- 不保存输入文字或按键历史。遇到密码框等安全输入时会暂停；安全输入结束后从♪菜单手动开始。

## 建议按这个顺序测试

1. 普通字母键、空格与左右修饰键；确认正常打字和快捷键仍可使用。
2. 在其他普通App输入，确认有琴声；用♪菜单调低/调高音量。
3. 移到屏幕底部中央唤出系统Dock，观察钢琴淡出；移开后观察淡入。只靠近底边但未出现Dock时不应误隐藏。
4. 关闭/开启按键标签；多键同时按下，观察声音与画面是否对应。
5. 若有外接屏幕或不同macOS版本，记录屏幕缩放、Dock位置与异常现象。

0.2.6包含16pt菜单、授权后的开始续接、重开入口和手动更新入口。0.2.4此前已通过本机普通实按发声、64音源集成、自适应宽度和底部Dock真实联动；这些历史实测不代替0.2.6首次安装后的输入授权与实按核对。仍待验证：Fn/Caps/左右键完整实按、多屏与侧边Dock、其他系统版本、蓝牙声学延迟和最终音色。Dock适配含隔离的私有SPI，不能把本机通过推定为所有macOS兼容。

## 反馈问题

在 [Issues](https://github.com/quennelwm/mac-typing-piano/issues) 新建问题，填写：Mac芯片、macOS版本、输出设备类型、复现步骤、预期与实际结果。有需要可从♪ → 测试 → 打开测试控制台导出诊断JSON；只有聚合计数，不含按键序列或音频录音。公开提交前请查看附件，不要附密码或无关私人资料。

## 校验与资源

下载页同时提供 SHA256SUMS.txt。在ZIP所在目录可运行 `shasum -a 256 -c SHA256SUMS.txt`。发布包与App主程序的SHA-256记录在仓库对应版本的 artifacts.json 中；0.2.6是包含16pt调整的新构建。

钢琴音源来自Versilian Studios VCSL的CC0-1.0资源；原许可和来源记录保留在App及仓库中。系统字体文件未随包分发。
