## 复现方法

项目根目录依次执行：

```sh
python3 Code/Scripts/verify_candidate_banks.py preflight
swift test --build-system native --package-path Code
python3 Code/Scripts/verify_candidate_banks.py summarize
python3 docs/evidence/C-001B/test_evidence_binding.py
```

以上全为离线测试，不需打开App或开启声音。Python使用现有jsonschema；不安装依赖。只重跑候选可在Swift命令追加`--filter CandidateBankTests`（3项）；完整命令包含C-001原有35项（合计38项）。输入或测试源码变更后必须重新预检、渲染，不能只汇总旧结果。`--build-system native`的弃用警告保留，原因沿用C-001 Desktop/FinderInfo构建限制。
