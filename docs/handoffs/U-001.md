在项目根执行：

```sh

python3 Design/UI/tools/build_preview.py
python3 Design/UI/tools/make_gifs.py
node Design/UI/tools/check_timeline.cjs
node Design/UI/tools/check_preview_logic.cjs
python3 Design/UI/tools/validate_ui.py
```
