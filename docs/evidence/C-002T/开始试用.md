# 打字钢琴试用 0.2.0

1. 打开 `/Users/wuming/Library/Caches/local.typingpiano.trial/打字钢琴试用.app`，确认标题为“打字钢琴试用 · 0.2.0”。
2. 点击“开始打字钢琴”。若提示缺少输入监控权限，按提示到系统设置手动允许这个新App，退出后重新打开，再点击开始。
3. 回到微信、文档等App正常打字。♪菜单可以调节音量、关闭声音/标签/钢琴、暂停或退出。持续会话没有60秒硬截止；随时暂停或退出。

全64音Steinway为可替换试用音色；顶部功能排不使用，Fn映射保留但实际捕获待验证。先用默认音量试听，再按个人舒适度调整。0音量不停止动画，调高不会补播旧音。

Dock默认模拟，不会随启动自动修改系统；真实Dock测试需从测试子菜单明确确认，读回不代表视觉已生效。测试子菜单中的两份局部候选只有10/11音位有声，换库会先停止，需要重新开始。

当前未完成真实Fn/Caps/左右修饰、中文/快捷键、Dock现场、设备切换/延迟和长时听感验收。若出现卡音或画面异常，先从♪菜单暂停或退出。权限属于新App标识，旧探针授权不保证沿用。此为本地ad-hoc试用包，无公证；原始C-001C入口由主对话保留。
