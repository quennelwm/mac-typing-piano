# Native Dock SPI integration decision — CODE evidence for main ADR

2026-10-28. PM explicitly approved the isolated dlsym backend after the user requested direct system Dock autohide control and the PM verified true→false→true visibly, without a Dock restart or new permission. Canonical ADR remains PM-owned; this file supplies the implementation decision and evidence.

Observed: defaults-only toggling changed stored value but did not change Dock visibility (`docs/evidence/PM-004-dock-adaptive/native-toggle-test.json`). HIServices CoreDockGetAutoHideEnabled/CoreDockSetAutoHideEnabled exist on this macOS27.2 arm64 host and in the local SDK export stub. PM observed UInt8 getter1→setter0/onscreen window49→setter1/no onscreen window, same PID1339; final defaults1. Source evidence: core-dock-toggle.json, core_dock_probe.swift, core_dock_toggle.swift in that PM directory. Code role only ran the default read-only getter/symbol probe (coredock-readonly.jsonl), never its guarded-toggle option.

Decision: independently implemented NativeDockStorage dynamically loads only these two functions, with UInt8 C Boolean ABI. Native getter owns the effective original/readback value. Setter verifies native readback and the existing fixed autohide preference read; mismatch throws and existing DockAdapter retains ownership/recovery evidence where needed. Missing symbols, invalid byte, ignored write or preference-read failure cannot report success; system-settings entry offers an explicit fallback. No defaults-write fallback, Apple Events, key injection, killall, third-party dependency or TCC change. Tests inject closures and do not load/call real setter.

Risk: these are private SPI, not an Apple public compatibility guarantee or App Store distribution claim. Current-host success does not establish macOS14 or future-OS compatibility. Detection failure must remain explicit. No other private functions are integrated. User-selected initial true is the restoration baseline; never restore an earlier false from before the user's system-UI change.

Historical external declaration reference, not copied program logic: https://github.com/rcarmo/qsb-mac/blob/master/QuickSearchBox/externals/UndocumentedGoodness/CoreDock/CoreDockPrivate.h . Local SDK exports and PM runtime evidence are the controlling current-host evidence. REA artifact inspection was not used to claim decompilation: the framework is in dyld shared cache and no standalone Mach-O existed at the probed path; no shared-cache extraction/installation was performed.
