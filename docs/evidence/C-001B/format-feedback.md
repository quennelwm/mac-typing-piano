根音/邻音的相对半音移调经过归一化自相关估计检查；最大相对误差约0.2734／0.2215 cents。该方法用标称周期限定搜索窗，不能作为独立绝对调音认证。Steinway高音估计约高10.8 cents，保留原文件交音效方评估，未自行修音。

四个根音均测50ms、1秒、5秒释放；600–800ms尾段全为零。MIDI96的5秒按压已超出其原始样本时长，释放前自然静音。500ms是SF2参数，不等同于实际听到的尾音时长。

在gain0.08及当前最大gain0.16下，覆盖音位同时以velocity127触发的混合峰值均低于1；最大增益时Kawai约0.0277232、Steinway约0.0318170。仅覆盖10／11音，不据此承诺64声部或所有力度/正式资源的防削波。10Hz重击、panic、gain0清尾/阻止新音、调高无重放、shutdown/reprepare均已离线验证。

`results.json` 把实际结果绑定到输入快照、测试/验证源码和代表WAV哈希；复现及数值方法详见本目录 `README.md`。全套工程通过以代码对话的最终全套日志为准，不能只看本目录聚合状态。
