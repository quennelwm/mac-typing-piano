# CR-001 系统Dock控制与恢复提案（只读调查）

状态：已采纳用户方向；只读调查/纯模型，不是实际系统写入验证。新用户期望自动隐藏=true，运行时实际值、执行成功与未知另列。本轮不触发写入或重启Dock。

## 候选机制

已只读执行 `/usr/bin/defaults read com.apple.dock autohide`；实际结果见 environment.json。`defaults` 是本机偏好工具；`com.apple.dock/autohide` 并非可承诺跨版本稳定的 AppKit 公共控制接口。建议后续 M1 受控试验用 Process 固定可执行路径/参数写该单一布尔键，再读回，不使用 shell 拼接、不修改其他键。更改是否立即生效、是否要刷新Dock，必须现场验证。若确需重启Dock，应单独向主对话说明对当前菜单/拖拽的影响并安排测试，本轮不执行 `killall Dock`。

不采用私有CoreDock调用、注入或 System Events UI脚本；后者可能增加辅助功能/自动化权限，超出本轮范围。构建/测试/预览不调用任何写设置函数。

## 三种状态必须分离

- desired：应用期望值；默认true。关闭先进入pending，显示指定警告和默认“保持自动隐藏”。只有“仍然关闭”才提交false；取消保持原偏好。
- observed：读取到的系统 Bool?；读取失败或值不合法即unknown，不默认false。
- apply：idle/pending/verified/failed/unknown；读回相同只证明偏好存储值，不证明Dock视觉已生效。读回不一致时提示失败，不循环写入。

## 所有权与恢复

在首次真正更改前，读取并保存original值；无法读取则不写。只在写后读回相符时登记 lastApplied 值。正常退出：重新读取，若当前值等于lastApplied且仍有所有权，恢复original并再读回；若已被外部改成不同值，放弃所有权并尊重现值。不把“外部改到同一布尔值”误说成可检测；布尔设置无法完整判断来源。

崩溃/强制结束无法保证恢复。后续可保存小型恢复票据（original,lastApplied,owner session），下次启动先读回并提示恢复选择，不能自动覆盖外部设置。需要测试受MDM管理、写入/读回失败、退出期间变化、重启Dock、崩溃和多个App竞争。M0只验证纯模型，系统效果全未测试。

## 用户警告文案

关闭自动隐藏后，Dock 可能与底部钢琴重叠或遮挡。仍要关闭吗？

按钮：保持自动隐藏（默认/取消）；仍然关闭。关闭不静音、不停止动画、不关闭钢琴自身避让。
