# PM-032 验收：0.2.9 透明度滑块

## 结论
接收C-032与U-032。本机固定路径已升级0.2.9/build12，输入监控许可保留，无重置或重新申请权限。原高度132%、音量100%、标签开启保持；默认透明度15%。已点击“开始打字钢琴”进入持续后台模式。GitHub发布回执待补。

## 实现
♪菜单新增“琴键透明度”0—100%滑块，数值表示透明程度，0%不透明、100%材质完全消失。材质合并一层透明，标签和浮音独立。黑键深灰#414B55/.84、白键浅灰#969FA9/.86。复用高度滑块250ms防抖、菜单关闭/退出补存与错误状态；减少透明度时强制实色、停用滑块并保留用户值。键位、音频、权限、Dock及浮音参数未改变。
